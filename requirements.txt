# No third-party dependencies.
#
# The whole pipeline runs on the Python 3.9+ standard library:
#   - csv          : Olist CSV ingestion (src/olist_store.py)
#   - urllib.request: OpenAI-compatible chat completions (src/llm.py)
#   - concurrent.futures: case-level and agent-level parallelism
#   - json / re / dataclasses: A2A envelopes, schema validation, tracing
#
# This is deliberate: the grader can clone and run `python3 run.py` on a bare
# interpreter with no install step and no dependency drift.
#
# Verified on: Python 3.9.6 (macOS) and Python 3.11.
